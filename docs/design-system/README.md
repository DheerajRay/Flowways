# FlowWays Design System Package

This folder is the pre-code design package for FlowWays.

Use these docs in order:
1. `00-system-charter.md` - theme, language, and non-negotiable principles
2. `01-ui-structure-blueprint.md` - page architecture and responsive behavior
3. `02-component-system-spec.md` - component inventory, states, and governance

## Figma Page Plan

Create three system pages in Figma from these docs:
1. `01 Layout System`
2. `02 Typography System`
3. `03 Component System`

## Delivery Workflow

1. Review and freeze principles in `00-system-charter.md`.
2. Build low-fidelity structural boards from `01-ui-structure-blueprint.md`.
3. Build tokenized components from `02-component-system-spec.md`.
4. Validate accessibility and interaction states before coding.

## Implementation Contract

No UI code should be finalized until:
- The three Figma system pages are complete
- Tokens and component states are documented
- Layout behavior is resolved for desktop/tablet/mobile
